Vibe Visualizer for Android 0.19.4 (beta). Android 12 or newer; it installs over 0.19.3 (Settings → Help & about → Update now).

### Fixes

- **Checking for updates works when GitHub says "too many requests"**: GitHub allows 60 checks an hour per connection without an account (shared by everything on the same Wi-Fi). When that's used up, the app reads GitHub's release feed instead, which has no such limit, and if even that fails it says until when GitHub won't answer
- "Updated to …" after an update no longer asks GitHub anything: What's new loads when you open Help & about

From 0.19.3: the heat warning, the skip and play / pause animations, and bigger controls on the Lyrics screen.
