Connect Spotify

Vibe Visualizer talks to Spotify through its official Web API. You need a free developer app, which takes about two minutes to create.

This page is open as a local file. Spotify login only works when it’s served from http://127.0.0.1, so start with step 1.

  1. Serve this page locally. In the folder that contains this file, run python3 -m http.server 8000, then open http://127.0.0.1:8000/index.html.
    Python docs: http.serverGet Python
  2. Create an app in the Spotify Developer Dashboard. Sign in with your normal Spotify account and press Create app.
    • App name and description: anything, for example “Vibe Visualizer” and “My music visualizer”.
    • Website: leave empty.
    • Which API/SDKs: tick Web API only.
    • Accept the terms and press Save.
    Developer DashboardSpotify guide: Apps
  3. Add this Redirect URI to the app (Settings → Edit → Redirect URIs), exactly as shown, including the / at the end, then Add and Save:
    Spotify guide: Redirect URIs
  4. Paste the Client ID. It’s on the app’s Settings → Basic Information page, a long code of letters and numbers. You don’t need the client secret, because Vibe Visualizer signs in with the PKCE flow.
    Spotify guide: Authorization Code with PKCE
  5. Add your Spotify account under the app’s Settings → User Management: your name and the email address of your Spotify account. Apps in development mode only work for users listed there, up to 25 people.
  6. Press Connect now and allow access. Spotify asks to see what you’re playing and to control playback.
    • The play, pause, skip and seek buttons, and clicking a lyric line to jump, need Spotify Premium. Everything else works with a free account.
    • Signed in once, the login stays on your server for this device.
    Spotify guide: Quota modes

Lyrics sources

Vibe Visualizer tries these in order and uses the first that has the song. Change the order or switch sources off in Settings → Lyrics.

  1. Spicy Lyrics: the best ones, synced word by word, with background vocals and duets. Needs a free key, kept on your server.
    • Sign in at the Spicy Lyrics developer site and create a New application. Name: Vibe Visualizer. Project URL: your copy of the project on GitHub (or https://github.com/BOZKOW/vibe-visualizer).
    • Create a secret key (it starts with sl_sk_). Don’t paste it into this page or share it.
    • Save it on the server as a file named exactly spicy_key in the helper’s config folder (next to docker-compose.yml). Any file manager works, for example ZimaOS Files. No restart needed.
    • Spicy Lyrics’ rules: the credits (provider, maker, uploader) always show while their lyrics are on screen.
    Spicy Lyrics dashboardTerms
  2. Spotify’s own lyrics and Canvas videos (optional, unofficial). The server opens a hidden Spotify web player with your login cookie.
    • Open open.spotify.com in your browser, signed in.
    • Press F12 → Application (Chrome, Edge) or Storage (Firefox) → Cookies → https://open.spotify.com, and copy the value of sp_dc.
    • Save it on the server as a file named sp_dc in the same config folder.
    • The cookie is your Spotify login: keep it private. This way of reading Spotify isn’t official and is against Spotify’s terms; leave it out if you’d rather not.
  3. LRCLIB and NetEase Cloud Music: no setup. LRCLIB is a free, open database; NetEase is strong for Chinese, Japanese and Korean songs. You can also drop your own .lrc or .ttml file onto the page.
    LRCLIB
  4. Translation and romanization: press T or R, or use the buttons in the top bar (they appear when a song needs them). Pick the language, and languages to leave alone, in Settings → Translation.
  5. Timing: lyrics re-sync with Spotify every 2 seconds. If they’re still always a bit early or late (Bluetooth headphones add a delay), press ] for earlier or [ for later while a song plays.

Sound for the bars

The bars react to sound. Local files work straight away. For Spotify, the bars need to hear what your computer plays. The easiest way is Vibe Bridge; otherwise press the microphone button in the top bar.

  1. Vibe Bridge (Linux and Windows, recommended): a small app that sends everything your computer plays, the Spotify app included, straight to the bars. No sharing, nothing to press each time. Download it from the GitHub releases and start it; the microphone button then turns green and says Vibe Bridge.
  2. Windows (Chrome or Edge): choose Share all computer sound, then in the window that opens pick Entire screen and turn on Also share system audio. That includes the Spotify app. Nothing is recorded or sent anywhere; the picture is ignored.
  3. Linux (Chrome, Edge, Brave): pick a 🔊 Monitor of … device for the speakers or headphones you listen on, then Start. It carries everything your computer plays, the Spotify app included. Allow microphone access when asked; that’s only how browsers list these devices.
  4. macOS: Chrome can only share a browser tab’s sound. Play Spotify in the web player at open.spotify.com, choose Share a browser tab, pick that tab and turn on Share tab audio.
  5. Firefox can’t share sound this way; use Chrome, Edge or Brave for the bars.
  6. Without shared sound, the bars still move with Spotify, but only as an imitation, not to the real music.

Install it as an app

Vibe Visualizer can run in its own window with its own icon, like any other app.

  1. Chrome, Edge or Brave on a computer: press the install icon at the right end of the address bar (a screen with an arrow), or ⋮ → Cast, save and share → Install page as app. In Edge: ⋯ → Apps → Install this site as an app.
  2. Android (Chrome): ⋮ → Add to Home screen → Install.
  3. iPhone and iPad (Safari): Share → Add to Home Screen.
  4. The app always loads the newest version from your server, so updates show up by themselves.
